# Raíces Andinas

Proyecto web exportado desde el diseño principal de Figma para continuar su edición en Antigravity.

## Archivos

- `index.html`: estructura de la página.
- `styles.css`: diseño adaptable para computadora y celular.
- `script.js`: interacciones del menú, buscador y botones.
- `assets/`: imagen e iconos locales.

## Vista previa

Abre la carpeta en Antigravity y ejecuta la vista previa de `index.html`. También puedes abrir `index.html` directamente en un navegador.

El proyecto no requiere instalación ni dependencias externas.
